# 기여 후보 신규성·연구 가치 반증

기준일: 2026-10-12. 판정은 현재 검토한 문헌과 개발 증거에 한정한다.
기존 연구 검토는 전 세계 문헌의 완전 검색이 아니므로, 아래 중복 판정은
“검토한 출처와의 중복”이지 전역적인 최초성 판정이 아니다.

## 결론 먼저

| 기여 후보 | 현재 판정 | 핵심 미충족 증명 부담 |
|---|---|---|
| 호출 방향을 전파 방향으로 해석·추적 | **현 설계 폐기** | 인과 전파 edge 정답 또는 독립적 개입 증거 |
| 규칙/학습으로 호출 edge·후보를 선별 | **일반 주장 폐기, 구체 기제 보류** | 기존 방법과 다른 선택 연산 및 같은 조건의 추가 효용 |
| LLM으로 카드/edge를 읽고 root-service 순위화 | **현재 기여안 폐기** | 강한 비LLM 대비 추가 정확도·재현성·비용 가치 |
| 작은 learner/MLP와 LLM 결합 | **조합만으로는 신규성 불인정** | 각 모듈의 독립 기여와 결합 상호작용 검증 |
| RCA의 근거 선별·root-service 진단 자체 | **분야 전체를 기각하지 않음** | 새롭고 검증 가능한 좁은 질문이 아직 특정되지 않음 |

## 주장별 겹침 지도

| 제안 주장 | 검토한 선행 방법과 구체적 겹침 | 현재 증거와 판정 |
|---|---|---|
| “장애 전파 방향을 따라 원인을 찾는다” | **MicroHECL**은 이상 경보에서 호출별 이상 연결을 고르고 전파를 역추적하며 상관 낮은 연결을 가지치기한다. **EviRCA**도 호출 관계를 도구로 조회하고 directed reasoning을 한다. 따라서 방향 활용·역추적 그 자체는 새 기여가 아니다. | RCAEval의 정답은 root service뿐이다. 관측 호출 방향은 인과 전파 정답이 아니다. 방향/edge 정확도는 채점할 수 없으므로 현재 데이터로 이 기여를 주장하면 안 된다. |
| “강한 피해 신호를 거슬러 원인을 찾아낸다” | 원인과 연쇄 증상을 구분하는 동기는 EviRCA가 이미 명시하고, TopoEvo도 큰 이상 서비스가 원인으로 오인될 수 있음을 다룬다. MicroHECL 역시 경보·호출별 이상을 구분한다. | 스모크나 개발 분석에서 비원인 후보가 실제 피해 서비스였다는 입증은 없다. 현상 이름을 ‘원인-피해 혼동’으로 고정하지 말 것. |
| “무관한 edge를 걸러 노이즈를 줄인다” | **MicroHECL** anomalous-edge pruning; **EviRCA** 통화 빈도 기반 최대 40개 연결 제한; **TopoEvo** 상위 후보의 H-hop 후보 부분그래프; **EG-RCA** 시간·토폴로지·이상·의미 규칙으로 근거 선별. 동일한 넓은 목적이 직접 존재한다. | edge 축소 또는 관련도 점수만으로는 신규성이 없다. **EG-RCA** 주 평가에서 규칙 파이프라인이 중심이며, 고정 12건 예비 LLM 위치 점수도 양쪽 75%로 동일했다. |
| “새 규칙으로 edge를 고르면 개선된다” | 위 네 방법의 선택/가지치기와 겹친다. 같은 개수 무작위 비교는 선별이 아니라 입력량 통제다. | 고정 smoke Top-1: 규칙 LLM 2/12, 전체 호출 1/12, 무작위 1/12, 카드만 1/12, 단순 수치 점수 11/12. 규칙 조건의 paired 승리는 각 비교에서 1, 패배 0, 동률 11이다. 효능도 신규성도 입증하지 못한다. |
| “학습 모델이 더 유용한 edge를 선택한다” | **TopoEvo**는 GAT 위치 추정과 학습된 상위 후보 기반 H-hop subgraph를 사용한다. 따라서 학습 기반 후보 선택+축소라는 수준의 주장은 이미 겹친다. EG-RCA도 규칙 선택을 가진다. | RCAEval에는 causal-edge gold가 없다. root-service label로 edge 전파 정답을 학습한다고 하면 표적 불일치다. 구체적인 root-supervised 목적함수도 아직 확립되지 않았다. |
| “LLM이 관계 방향과 카드 근거를 추론한다” | **EviRCA**는 결정적 evidence cards와 directed reasoning/tool access를 분리한다. **TopoEvo**는 후보 부분그래프와 검증 에이전트를 결합한다. **EG-RCA**는 선별된 관측 근거를 LLM에 준다. | LLM 호출은 역할 차별성의 증거가 아니다. 현재 고정 smoke의 각 LLM 조건은 1–2/12 Top-1로 11/12 단순 점수보다 낮았다. 한 8B 설정 결과로 모든 LLM을 반증할 수는 없지만, 추가 가치를 먼저 증명해야 한다. |
| “작은 MLP/learner와 LLM을 결합한다” | 검토한 각 요소의 결합/순서 조합은 이미 후보 위치 추정·subgraph 선택·근거 카드·LLM reasoning에서 부분적으로 나타난다. 모듈 이름이나 조합 순서는 새 지식이 아니다. | 학습 데이터 36은 12개 반복 그룹의 세 반복 관측이지 독립 조건 36개가 아니다. 선택 라벨·누출 방지·시험군도 확정되지 않았다. ablation과 독립 그룹 시험 없이는 모델 복잡도만 늘어난다. |
| “정확도를 조금 올리면 기여가 된다” | MicroHECL/EviRCA/TopoEvo/EG-RCA가 이미 RCA 정확도·후보 축소/근거 선택을 다룬다. 차별성은 점수 하나가 아니라 연산·정보·비용·적용 조건으로 보여야 한다. | 12건의 1건 차이, 개발 결과의 marginal gain, 또는 선택 후 점수 상승은 독립 시험·불확실성·강한 baseline을 넘지 못하면 출판 기여를 보장하지 않는다. |

## 결과가 말해 주는 것과 아닌 것

- 검증된 개발 분석: 중앙값 변화 30/36 Top-1, 35/36 Top-3; BARO 코드 정렬
  NumPy 점수 재구현 signed 10/36, absolute 변형 10/36. 이는 전체 BARO 재현이
  아니며 held-out 성능도 아니다. 원래 smoke 12건/특징/결과는 그대로다.
- 중앙값 기준점의 오류는 delay 1/6, mem 5/6, 다른 fault 유형 6/6 Top-1이다.
  따라서 다수 쉬운 그룹을 이미 맞히는 자료에서 복잡한 방법의 여지는 작고,
  지연 실패가 반복되는 그룹에 대한 사례 근거를 먼저 요구한다.
- 개발 36건은 12개 시나리오 그룹×3 반복이다. 통계적 독립 표본 36개로 세지 않는다.
  보호된 나머지 144건은 읽거나 평가하지 않았다. 이 결과를 시험 성능으로 부르지 않는다.
- BARO 수치도 논문 전체 재현이나 공정한 모든 baseline 비교가 아니다. 두 구현은
  서로 다른 방법 묶음이며 점수 차이를 새 기여의 근거로 과장할 수 없다.
- 정확한 결과·실패 사례: `../baselines/baseline-audit.md`; smoke 결과·paired 제한:
  `../verification/smoke-audit.md`, `../verification/decision.md`.

## 살아남을 수 있는 기여의 최소 조건

1. **문제 근거:** 기준점 실패가 실제 root-service 오진인지, 어떤 관측 정보의 부족/
   표현/순위 오류인지 반복 그룹 단위 사례 증거를 제시한다. “피해자 혼동”은 피해
   정답이 없으므로 별도 증거 전까지 사용하지 않는다.
2. **구체적 차별 기제:** 선행법과 다른 연산, 학습 표적, 가용 입력, 실패 조건을
   명시한다. 단순히 방향, pruning, 후보 top-k, GNN/MLP, LLM을 조합하는 것은 부족하다.
3. **표적 정합:** 주장은 우선 root-service Top-1/Top-3로 제한한다. edge 인과 성능은
   RCAEval label로 입증할 수 없다. 전파 방향/edge 기여를 유지하려면 그 주장에 맞는
   별도 causal-edge gold나 개입 기반 검증이 새로 필요하다.
4. **공정 비교:** 같은 후보·입력 정보·시작 시각·예산에서 강한 단순 점수, 규칙,
   동일 크기 무작위 선택 및 재현 가능한 관련 방법과 비교한다. 기존 논문 점수 인용은
   우리 데이터의 재현/우월 비교가 아니다.
5. **효용 판정:** 독립 반복 그룹으로 분할한 미사용 시험군에서 root-service 정확도
   개선을 보이고, paired 불확실성·실패 유형·비용을 공개한다. learner, LLM, edge 선택은
   각각 제거하는 ablation으로 추가 기여를 분리한다. 작은 이득이면 비용 대비 가치도 입증한다.
6. **LLM 통과 조건:** LLM은 비LLM 기준점이 실패하는 확인된 오류를 고치는 구체 역할이
   있어야 한다. 같은 정보의 비LLM 대안보다 정확도 또는 정당화 가능한 운영 효용이
   재현성 있게 좋아야 한다. 자연어 설명, 그럴듯한 인과 서술은 진단 성능이 아니다.

## 문헌 범위 및 인용

아래는 검토 문서에 기록된 원문/저자 코드다. 이 대조는 지정된 방법의 중복을
구체화할 뿐, 포괄적인 검색·전 세계 최초성 조사를 뜻하지 않는다.

- MicroHECL, ICSE-SEIP 2021, anomalous-edge pruning:
  https://arxiv.org/abs/2103.01782
- EviRCA, 2026-09-17 preprint, evidence cards/directed reasoning/call-frequency cap:
  https://arxiv.org/html/2609.19825v1 ; https://github.com/yuhao541/EviRCA
- TopoEvo, 2026 preprint, learned candidate localization/H-hop subgraph:
  https://arxiv.org/html/2605.15611v1
- EG-RCA, evidence selection and LLM; pilot localization unchanged:
  https://7universum.com/en/tech/archive/item/23417
- RCAEval labels and scope: `../verification/data-readiness.md`;
  literature method summaries and caveats: `../관련연구_분석.md` §§1, 4–7.

**종합 판정:** 전파 방향을 인과 방향으로 읽는 현 설계와 일반적인 edge-selection
주장은 폐기한다. LLM/작은 학습기의 결합도 현재는 기여가 아니다. 다만 이는 이 특정
설계의 증거 부족·선행 중복 판정이지 RCA 분야 전체의 무가치 판정이 아니다. 새 기제,
그 기제가 필요한 실패 증거, 표적에 맞는 평가가 나오기 전까지 방법 기여는 보류한다.
