# 비교적 작은 MLP의 비용–정확도 연구 준비

## 사용자 요청과 범위

2026-10-13 요청: 경량성을 미리 주장하지 않는다. 같은 계산 예산의 정확도,
유사 정확도의 시간/메모리, 적은 학습 사례의 안정성을 평가할 기준을 마련한다.
선행연구를 과제·입력·전처리 포함 비용·모델/자료 규모·공개 구현의5축으로
다시 선별한다. DiagMLP/현재 제안 모델의 실제 흐름을 그림으로 설명한다.
현재 자료의 GB/GiB를 측정하고 사건 단위 개발 평가에 쓸 전처리 자료를 준비한다.

이번 작업은 이 요청에 한정된 재선별·측정·자료 준비다. 모든 RCA 문헌을 망라했다거나
이미 비용 우위를 입증했다는 주장은 하지 않는다.

## 실행 의존성

1. 비용 계약과 자료 경계를 먼저 기록한다.
2. 독립 작업: 관련 방법 선별 / 확장 데이터 후보 확인 / 기존 개발 자료의
   사건별 재분할·정상 참조 재계산. 주 에이전트는 실제 용량 측정과 모델 흐름 검증을 맡는다.
3. 선행연구 근거와 자료 검증을 합쳐 비교 목록·비용 계약·용량표를 완성한다.
4. 검증된 모델 구조로 흐름도를 생성하고 산출물·한계를 설명한다.

## 변경/보호 경계

- 새 산출물은 이 폴더에만 저장한다. 기존 코드·분할·특징·모델 결과는 변경하지 않는다.
- 새 모델 학습이나 기존 최종시험 채점은 하지 않는다.
- RCAEval 최종36건의 원자료를 열지 않는다. 그 전체 용량은 기존 확보 명세의
  파일 크기로만 산정하고, 명세가 불충분하면 미확인이라고 기록한다.
- native test/unassigned 창은 새 개발 묶음에서 제외한다.
- 새 사건 분할은 이미 개발 중 관측한 사건을 재구성한 것이다.
  독립된 미접촉 최종평가나 새로 수집한 반복 사례로 부르지 않는다.
- 대규모 다운로드·패키지 설치·원저자 연락·프로젝트 commit은 하지 않는다.
- 결과를 보고 분할·허용 오차·비용 한도를 고르는 작업은 하지 않는다.
