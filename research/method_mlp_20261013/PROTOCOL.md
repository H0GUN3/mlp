# 자체 기준선과 상대 특징 제안 모델

## 사용자 결정과 범위

2026-10-13: 사용자는 원 논문 SN/TT 자료를 선택했고, 이어
“원 논문의 모델을 개선 시킬 필요는 없으며 제안한 방법론에 따라
기준(basesline)을 만들고 제안 모델을 만들어야함”이라고 명확히 정정했다.
이 문서가 앞선 ‘원형 모델에 비교 기능 추가’ 구상보다 우선한다.

- 논문 복원본 Eadro/DiagMLP는 변경하지 않는다. 외부 비교 자료다.
- 자체 기준선과 제안 모델을 독립적으로 구현한다.
- 기준 설계: `research/MLP_방향평가_및_설계.md` §5.1–5.3.
- RCAEval 특정 사건의 충실한 원형 재검증은 미확인으로 남긴다.
  RCAEval 최종시험36건과 원 논문 자료의 test 예측은 이번 개발에서 열지 않는다.
- 서비스 신원 일반화를 입증했다고 주장하지 않는다. 현재 검증 분할은
  시간창이 분리되어도 같은 주입 사건을 공유한다.

## 고정 비교

| 항목 | 자체 기준선 local | 제안 모델 relative |
|---|---|---|
| 서비스별 정상 대비 변화 x | 사용 | 동일 |
| 실제 유효 관측 mask와 관측 비율 q | 사용 | 동일 |
| 서비스 이름·위치 임베딩·정답 유형 | 사용 안 함 | 사용 안 함 |
| 호출 그래프·이웃 특징 | 사용 안 함 | 사용 안 함 |
| 사고 내 유효 서비스 평균 c 대비 x-c | 사용 안 함 | 사용 |
| 서비스별 점수기 | 공유 MLP 32→16→1 | 동일 |

비교하는 핵심은 **사고 내 상대 비교 정보의 추가 효과**다. 관측 품질은
양쪽에 동일하게 제공해 그 효과를 상대 비교와 혼동하지 않는다.
이 구조와 상대 특징 자체의 신규성은 입증되지 않았다.

## 데이터·특징 계약

검수된 `native_inputs/{SN,TT}/raw.npz`, metadata 및 기존 seed42 분할을 사용한다.
후보·라벨·10초 창·시간대 보정·원자료 중복 보존 정책을 바꾸지 않는다.
학습 정상 창만 정상 참조값 산정에 사용한다. 모델 학습/검증은 해당 분할의
고장 창만 사용한다. 서비스당 행을 독립적인 사고로 세지 않는다.

핵심 설계에 맞춰 메트릭 7채널과 trace 지연/retained-span-count 2채널을 사용한다.
새 모델에 Hawkes/TCN을 이식하지 않는다. 로그 활용이나 별도 탐지기는 이번
두 모델의 범위가 아니다. 이는 자체 방법 실험이지 원 논문 전처리 재현이 아니다.
논문 모델과 입력 가공·학습 목적이 다르므로 논문 성능을 재현했다고 부르지 않는다.

- 메트릭은 검수된 원 배열을 사용한다. 완전한 CSV 관측 범위/해시 근거를 확인한다.
- trace 원본을 한 번 읽어 초별 span 개수와 평균 지연을 복구하고 기존 지연과
  일치함을 검사한다. 0 지연이라도 span이 있으면 유효 관측이다.
- span 0개일 때 지연은 결측이다. 개수 0은 ‘기록된 span 0개’이며,
  수집기가 정상 작동했다거나 실제 요청 0개였다는 보장은 아니다.
- 서비스별·채널별 학습 정상 참조 median과 IQR을 산정한다.
  scale=max(IQR, 0.05*abs(median), 1e-8). 참조 관측이 없으면 그 채널은 결측이다.
- 초별 z=(value-median)/scale에서 signed-log 평균과 |z|>2 지속 비율을 계산한다.
  9채널×2=18개 특징. mask는 현재 관측과 정상 참조가 모두 있을 때만 참이다.
  q는 해당 창의 유효 관측 초 수/10이며 각 특징에 대응한다.
- 결측 특징은 숫자 0과 별도 mask로 표현한다. 정상 0과 동일시하지 않는다.
- c는 채널별 유효 서비스 x의 평균(자신 포함). 전부 결측이면 context mask=0.
  x-c는 자신의 mask와 context mask가 모두 참일 때만 유효하다.

두 모델 입력 폭을 `[x, relative, own_mask, q, context_mask]`로 동일하게 한다.
local은 relative와 context_mask 슬롯이 0이다. 같은 은닉 폭·초기 가중치·총
파라미터 수를 유지하되 local의 0 슬롯 가중치는 학습 신호를 받지 않는다.
이는 입력 제거 실험이며 ‘유효 표현 용량까지 동일하다’는 주장은 하지 않는다.

## 학습·선택·채점

- 앱별 별도 학습, seeds 11/23/37, 동일 초기화와 minibatch 순서.
- Adam lr=1e-3, weight_decay=1e-4, batch32, 최대200epoch, patience30.
- root-service softmax cross entropy. 사건별 고장 창 수의 역수로 가중해
  한 사건의 창 수가 많다고 더 큰 총 학습 가중치를 주지 않는다.
- 학습용 변화량의 유효 값만으로 특징별 표준화를 학습한다. 양쪽 공통이며
  상대 평균은 이 공통 표준화 이후 계산한다. 결측 값은 통계에서 제외한다.
- 검증 사건 균등 평균 CE가 가장 낮은 checkpoint를 선택한다.
- 주지표: 사건별 창 Top-1 평균을 사건 간 균등 평균한 점수.
  창 단위 Top-1도 함께 보고해 기존 논문 복원본과의 조건 차이를 드러낸다.
  동점은 정답이 최대점 집합에 있을 때 1/동점수로 채점하고 유일 정답률도 보고한다.
- 두 앱·세 seed의 모든 결과를 보고한다. 유리한 앱·seed·특정 오답만 골라
  개선이라 하지 않는다. 성능이 나빠지면 그대로 보고하고 사후 분할/특징 탐색하지 않는다.
- 원 논문 복원본 결과는 외부 참고이며, 자체 기준선 대비 개선이 곧 선행법보다
  우수함을 뜻하지 않는다. 탐지 성능·미관측 사건 일반화는 주장하지 않는다.

## 실행 DAG와 검증

`특징 준비`와 `모델/학습기 구현` → 합류 → `SN·TT 각 local/relative 학습`
→ `checkpoint 재실행·독립 재채점` → 한국어 비교 보고.

특징 검증: 정상 참조 TRAIN 전용, 실제 span counts/0-duration/결측 구별,
해시·기존 지연 일치, held-out 비사용, 정상 참조 없는 채널, 유효값만의 통계.
모델 검증: 서비스 순열에 따른 점수 대응, 결측 placeholder 불변,
all-missing context, local의 다른 서비스 입력 독립성, 두 모델 초기화/크기,
유한 loss·gradient, 학습·저장·재실행 일치.
기존 소스/결과는 수정하지 않고 새 폴더에만 산출물을 쓴다.
