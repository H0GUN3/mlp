# 비용 외삽 재검토

## 판정

저장된 측정만 재산술했다. 전체 고유 입력 80,028개를 처리하는 비용은 3개 표본의 산술평균을 쓸 때 단일 작업자 환산 512.881시간, 4작업자 이상적 분할 128.220시간이다. 유효 캐시에 이미 있는3개를 제외한 **잔여80,025개**는 같은 가정에서128.215시간이다. 16작업자의 32.055시간은 전체4작업자 환산을 다시4로 나눈 완벽한 선형가속 가정일 뿐, 병렬 실측값이 아니다. 이 외삽은 저장된2시간 예산을 크게 넘지만, 실제 전체 처리 시간을 측정한 것은 아니다. 입력 표현·solver 설정은 변경하지 않았다.

Hawkes 전처리의 seed42는 신경망 학습 seed11/23/37과 별개다.
현재 계약에서는 완성된 입력 묶음을 세 학습 시드가 공유하므로 전처리 비용을3배로 계산하지 않는다.

## 입력·측정 근거

| 항목 | 확인값 |
|---|---:|
| 고정된 분할 | TRAIN 48 / validation 24 (총 72사례) |
| 템플릿 차원 | 1,025 |
| 기준선 입력 위치 | 143,822 = 비어 있지 않은 91,060 + 실제 빈 위치 52,762 |
| 비어 있지 않은 위치의 정확한 고유 knot-key | 80,028 |
| 이미 제거된 위치 중복 | 91,060 − 80,028 = 11,032 |
| 3개 표본의 실행 시각 | 11.410171868, 14.278112400, 43.526409419초 |
| 표본 반복 수 / cap 여부 | 11 / 미도달, 21 / 미도달, 50 / 도달 |
| 경고 목록 | 각 표본 `[]`; 수렴 증명은 아님 |

143,822 위치는 10,273창 × 14노드로 확인했다. preflight의 `retained` 노드 수를 각 사례별로 합산하는 방식은 빠진 노드가 있는 사례를 축소 계산하므로 이 총계 검산에 사용하지 않았다. profile이 기록한 91,060 비어 있지 않은 그룹과 52,762 빈 그룹의 합은 143,822다. 80,028개 고유 입력의 재사용은 정확한 key 기준이다. 세 번째 프로브는 cap 50에 도달했으므로 표본시간은 완료까지 걸린 시간이지 수렴시간 보증이 아니다.

표본은 첫 사례 `re2ob_checkoutservice_cpu_1`의 knot 크기 최소·중앙·최대 세 위치뿐이다. 모두 `event_count=1025`, `seed=42`, `iteration_cap=50`, 단일 thread이며 입력 바인딩 SHA256은 `e65db027735a564075197173189bc7bdfb2672dd42401aae23370e5a7f8e534c`다. 첫 표본 PID 1551780은 기존 profile 측정 재사용이고, 나머지 표본은 PID 1603388에서 측정됐다. 따라서 세 표본은 전체 80,028개나 72사례를 대표한다고 입증되지 않았다.

검산은 저장 JSON의 카운트·입력 바인딩·표본 수와 초 값을 직접 대조했다. 사례별 preflight `retained` 노드 수에 창 수를 곱해 전체 위치를 재구성하려 한 보조 검산은 133,693을 내어 143,822와 불일치했다. 관측/retained 노드가 14개 미만인 사례가 있어 이 산식은 전체 위치 검산에 부적절하다. 음성 결과를 기록하며, 대신 10,273창×14노드와 profile의 `91,060+52,762` 일치를 사용했다.

## 외삽 산술

| 시나리오 | 산식 | 추정 시간 | 해석 |
|---|---|---:|---|
| 단일 작업자, 표본 평균 | `80,028 × mean(3개 초) / 3,600` | 512.881시간 | 단일 작업자 환산 |
| 단일 작업자, 표본 최대 | `80,028 × max(3개 초) / 3,600` | 967.592시간 | 전체 입력에 최대 표본시간을 적용한 산술 상한 시나리오; 실제 상한 보장 아님 |
| 4작업자, 표본 평균 | `80,028 × mean(3개 초) / 4 / 3,600` | 128.220시간 | 4배 이상적 분할 가정 |
| 4작업자, 표본 최대 | `80,028 × max(3개 초) / 4 / 3,600` | 241.898시간 | 4배 이상적 분할 가정; 상한 보장 아님 |
| 16작업자, 평균의 이상적 분할 | `80,028 × mean(3개 초) / 16 / 3,600` | 32.055시간 | 16배 완벽한 선형가속 가정, 실측 아님 |

재계산된 4작업자 평균 128.220시간과 최대 시나리오 241.898시간은 cost_supplement의 반올림 전 저장 초 값과 일치한다. 이전 profile은 첫 표본 1개만으로 4작업자 평균·최대 모두 63.412시간으로 산출했으나, 세 표본 추가 후 평균은 128.220시간으로 바뀌었다. 따라서 한 표본 외삽보다 세 표본 외삽이 크며, 둘 다 분포 대표성이나 신뢰구간을 제공하지 않는다.

## 이미 사용한 비용과 미실행 비용

| 단계 | 이미 기록된 시간 | 회계 처리 |
|---|---:|---|
| 정상 TRAIN 템플릿 적합 | 626.046300초 (0.173902시간) | 완료된 비용 |
| 매칭/profile 단계 | 1,696.294516초 (0.471193시간) | 완료된 비용; 매칭 및 profile 관측 구간 |
| 중복 profile producer | 별도 확정 시간 없음 | 복구 기록에 중복 실행 및 후발 PID 종료가 명시됨; 시간을 모르는 비용은 위 두 값에 임의 가산하지 않음 |
| 프로브 fit | profile 안에 첫 표본 11.410172초 포함; supplement 측정 구간 63.450614초 | supplement의 첫 표본은 기존 profile 측정 재사용이며, 추가 실제 fit은 두 건. profile과 supplement 시간은 겹치는 측정이 있어 합산하지 않음 |
| 나머지 고유 입력 | 80,028개 전체의 표본 외삽으로 추정 | 이미 계산된 표본·캐시의 key별 전체 현황을 재조회하지 않았으므로 실제 미완료 수와 실제 잔여시간은 확정하지 않음 |

따라서 128.220시간은 “80,028개 전체를 표본 평균으로 추정한 4작업자 이상적 환산”이지, 이미 수행된 probe 시간을 차감한 정확한 미완료 잔여량이 아니다. 템플릿·매칭/profile 비용은 별도 이미 사용한 비용이며, 외삽에 다시 더하지 않았다. 중복 producer의 실제 추가 시간도 근거가 없어 미확정이다.

## 한계 및 보존 범위

- 창/사례/노드/로그 밀도별 실행시간 분포를 전수 측정하지 않았고, 세 표본은 첫 사례의 knot 크기 위치 3개에 국한된다.
- 4·16 작업자 병렬 wall time, CPU 경쟁, I/O, 메모리 압력 및 작업자 간 편차는 측정하지 않았다. 선형 나눗셈은 계획 예산용 이상적 산술일 뿐이다.
- 평균·최대 외삽은 표본 기반 시나리오이지 신뢰구간, 수렴 보장, 전체자료 상한이 아니다. 경고 없음도 수렴 증거가 아니다.
- duplicate producer의 실제 추가 비용은 수치화할 근거가 없어 미확정으로 남겼다.
- 절감 우세 항목은 이 자료만으로 입증되지 않는다. 고유 중복 제거는 11,032개 위치의 재계산 회피가 확인되지만, 수치 병목 우세성은 numerics profile 없이는 판단할 수 없다.
- 비용 검토만 수행했다. 48/24, 보호된18사례, 1,025 템플릿 특징, seed42, HawkesADM4 decay3 / baseline0.2 / native initial random adjacency / max_iter50 / tol / history 계약을 바꾸지 않았다. 새로운 solver 실행·neural fit 또는 inference·원본/코드 수정은 이 보고서 작성에 포함하지 않았다.
