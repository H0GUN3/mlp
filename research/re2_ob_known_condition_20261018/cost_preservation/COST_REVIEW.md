# 비용 보존 검토 — 2026-10-18

## 결정 요약

**대표 입력의 최종 특징값 보존은 통과(5/5), 엄격한 프로토콜은 불완전, 2시간 예산은 불통과다. 운영 적용이나 전체 80,028개 입력의 동등성은 승인하지 않는다.**

정확한 0 행·열만 줄여 SVD를 수행하는 후보는 다섯 입력 모두에서 1,025차원 최종 `float32` baseline 배열이 원형과 정확히 같았고, 반복 수와 경고도 같았다. 그러나 네 입력의 `float64` baseline은 달랐으며, 첫 원형 profile은 fit 뒤 pandas 전이 import 검사에서 실패해 profile 결과를 저장하지 못했다. 따라서 대표 결과는 유효하나, NUMERICS에 기록된 전체 프로토콜 성공으로 바꿔 말할 수 없다. 실수 연산의 수학적 항등식도 전체 입력의 유한정밀도·비트 동일성을 증명하지 않는다.

### 현재 병목과 이미 적용된 절감

- 기준선 143,822개 위치는 비어 있지 않은 91,060개와 실제 빈 위치 52,762개다. 빈 위치는 0벡터이므로 fit 비용이 없다.
- 고정 seed 42에서 정확한 knot-key로 묶으면 비어 있지 않은 위치는 80,028개 고유 입력이다. 이미 동일 입력 11,032회분의 중복 fit을 피하고 있다. 이 중 실제로 검증된 캐시는 3개뿐이며, 남은 고유 입력은 80,025개다. 80,028개 모두 캐시되어 있다는 뜻은 아니다.
- 기존 `cached_fit`의 key·provenance 조건을 만족하는 세 cache pair만 재사용 가능함을 확인했다. 캐시 확대를 위해 knot·템플릿·시각·seed를 바꾸지 않았다.
- 실제 `reference-3`의 1,025차원 교차 사례에서 fit 35.592초 중 SVD 39회가 23.928초(약 67.2%), 행렬 `dot` 4.798초, native ADM4 EM solve 3.432초, 상대거리 계산 1.350초였다. SVD 시간에는 prox와 objective `value`의 SVD가 포함된다. prox 전체 25.561초와 `value` 전체 3.473초는 SVD·행렬곱을 포함하므로 위 시간에 더하지 않는다. 이는 email/socket 사례의 계측이지 전체 사례의 고정 비율이 아니다.
- 따라서 확인된 후보는 정확한 영구조에서 SVD 차원과 계산을 줄인다. 원형 solver·초기값·objective·기록·종료조건은 바꾸지 않는다. 작은 값 pruning, objective 생략, tolerance·iteration 축소는 하지 않았다.

### 다음 결정 요청 — 제안만, 자동 변경 금지

현재 계약과 2시간 한도를 동시에 유지할 근거는 없다. 다음 중 하나를 담당자가 구체적으로 결정해야 한다.

1. **특징·자료 범위를 유지:** 현재의 48/24 분할, 모든 사례·창·이벤트·1,025차원 특징과 원형 solver를 유지하고 계산 예산을 늘릴지 결정한다. 원형의 4-worker 외삽은 약128.22시간이며 실제 완료시간 보장이 아니다. 후보의45.71시간을 원형 비용으로 대체하지 않는다. 먼저 실제 병렬 처리량과 자원 한도를 확인하는 제한된 단계가 필요하며, 현재 장시간 실행은 승인받거나 시작하지 않았다.
2. **사건 수는 유지하고 표현 변경을 검토:** 구체적인 제안은 새 TRAIN48의 주입 전 로그 출현 횟수 상위256개 기존 Drain 템플릿을 유지하고, 동률은 기존 template id 오름차순으로 정하며, 나머지와 미일치 로그를 unknown에 모으는 **257차원** 입력이다. validation 빈도·정답·결과는 선택에 쓰지 않는다. 모든48/24 사례·창·로그 시각·소유 서비스는 유지하고, 바뀐 이벤트 배열로 Hawkes를 다시 적합한다. 기존1025차원 baseline을 단순히 잘라 쓰지 않는다. 희귀 템플릿 구별이 사라지고 unknown 이벤트 과정과 Hawkes 추정값이 달라지므로 원형과 같은 특징값이 아니다. 256은 비용 탐색용 제안값이지 검증된 최적값이 아니다. 실제 비용·남는 고유 입력 수·성능 영향은 미측정이며, 2시간 충족이나 차원 수에 비례하는 가속을 약속하지 않는다. 사용자 결정 전 매핑·적합·학습은 적용하지 않는다.

**주 담당의 범위 교정:** TRAIN 사례·창을 줄이는 대안은 요청한 전체48/24 기준선·오류 분석을 훼손하므로 기본 진행안에서 제외한다. 위 두 안은 결정용 제안이며 어느 쪽도 실행하지 않았다. 후보 수치 최적화도 운영 경로에 적용하지 않는다. 이 문서는 baseline 오류 분석을 위한 비용·값 보존 검토이며 입력 최적화 연구나 모델 성능 평가가 아니다.
