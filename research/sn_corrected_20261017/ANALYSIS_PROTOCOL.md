# 결과를 보기 전 고정한 분석 범위

1. 각 모델/seed의 외부평가는36사건이며, 각 사건은 한 순환에서만 평가한다.
   두 모델×세seed×36의216개 예측을216개의 독립 사건으로 세지 않는다.
2. 순환/seed별 Top-1·Top-3,36사건을 합친 seed별 결과와3seed 평균을 보고한다.
   기존 창 정확도·사건별 창 적중률 평균과 직접 차감하지 않는다.
3. 사건별 두 모델의 seed 평균 차이, win/tie/loss, 종류별12사건 결과,
   recording별9사건 결과와 고정된4cluster bootstrap 범위를 기록한다.
4. 각 선택 checkpoint의 TRAIN/validation/evaluation 사건 오류를 나란히 확인한다.
   학습 중 joint loss와 선택 모델의 추론 root NLL은 다른 양이다.
   선택epoch/업데이트/연장/예산한계를 같이 보고하고 수렴을 과장하지 않는다.
5. root 빈도 기준선은 TRAIN의 사건 수만으로 계산한다.
   각 root가1사건이라 모두동률이며 기대Top-1=1/12,Top-3=3/12여야 한다.
6. 오류를 진단할 때 기존 허용 SN 관측감사의 원인 trace 존재/경계창/비원인 후보를 연결한다.
   이는 점수 고정 뒤의 설명이며 입력 선택·사례 제외·재튜닝에 사용하지 않는다.
   비원인 후보를 피해 서비스로 자동 명명하지 않는다.
7. 관측 부족, 앞단 정보 손실, 학습 부족, 후단 구조 문제를 구분한다.
   상관된 오류 패턴만으로 하나의 원인을 확정하지 않는다.
8. 독립 채점은 scores.py를 그대로 다시 호출하는 것으로 끝내지 않는다.
   저장된 logits/labels/indices의 대응과 다른 구현의 stable probability pooling/동률 계산을 대조한다.
   모든 선택 checkpoint를 다시 추론해 저장 예측과 대조한다.
9. 새 기법의 개선 결과가 아니라 기준법의 교정 평가다.
   보완이 필요하면 확인된 실패 하나에 연결되는 변경 하나만 후속 후보로 제안한다.
   이번 실행에서 자동으로 추가 모델이나 새 자료 실험을 시작하지 않는다.
