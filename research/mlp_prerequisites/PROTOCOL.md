# 비교 모델 실행 선행조건 검증 명세

성능 결과를 보기 전에 고정한다. 제안 방법은 학습하지 않는다.

## 데이터 경계

- 기존 metadata `data/rcaeval/cases.parquet`에서 RE2-OB/TT 180건만 사용.
- 그룹: 시스템/원인 서비스/장애 종류. 반복 1·2·3을 분리하지 않음.
- 기존 개발 36건은 학습에만 배치. 최종 시험 및 검증으로 재활용하지 않음.
- 학습108/검증36/최종시험36. 시스템별 54/18/18.
- 각 시스템/장애 종류에서 기존 개발 1그룹은 학습, 나머지 4그룹은
  학습2/검증1/시험1. 모든 분할이 시스템별 원인 서비스 5종을 포함하도록
  metadata만으로 seed20261012의 결정적 순서를 탐색한다.
- split manifest와 hash를 저장한 다음에만 신규 학습/검증 관측자료를 읽는다.
- **이번 코드는 시험 관측자료를 읽거나 채점하는 실행 모드를 제공하지 않는다.**

## 비교 경계

- `DiagMLPCommonInput`: 논문의 모달 결합/위치 표현/전체 노드 결합 구조를
  재구현한 common-input 변형. 원 저자 코드나 전체 논문 재현이라 부르지 않음.
- `EadroGATCommonInput`: 원 저자 GraphModel을 고정하여 공통 특징과 원인 head에 연결.
- 실제 관측 호출 관계는 Eadro 입력으로 제공. MLP가 topology를 직접 쓰지 않는 것은
  방법의 차이이며, Eadro에서 관계 정보를 제거하여 불리하게 만들지 않음.
- 별도로 원 저자 MainModel 전체의 합성 입력 forward/backward를 점검.
- 고유 로그·TCN 전처리를 common-input 비교에서 재현하지 않는다. 따라서 결과는
  원 논문의 end-to-end 성능이나 기존 최고 성능 대비 우수성을 뜻하지 않는다.

## 공통 입력

고정 지표 계열: cpu, mem, latency-50, latency-90, workload, error.
각 계열의 정상 대비 중앙값 차이를 max(정상IQR, |정상중앙값|×0.05, 1e-9)로
나누고 signed-log1p로 안정화한다. 100점 상한/반올림은 하지 않는다.
계열별 유효성 mask를 별도 제공. 각 구간 유효 관측 20개 미만이면 결측이다.
트레이스: 정상/장애 span 빈도(관측 기간으로 정규화), duration 중앙값 비율의 log,
비율 유효성 mask. 과거 검수된 개발 cache를 재사용할 때 trace ratio는 기존 3자리
정밀도를 유지하고 새 추출도 동일하게 반올림한다. service-present mask를 추가한다.
전체 17차원. 신규 제안의 상대 특징은 이 단계에 넣지 않는다.

정답·장애 유형·사례명은 모델 입력이 아니다. 서비스 이름은 고정 후보 위치로 사용되며
서비스 신원 불변/미관측 서비스 일반화 실험이라고 주장하지 않는다.
후보 어휘와 표준화 평균/표준편차는 학습 자료로만 결정한다.
검증에서 처음 나타나는 서비스는 조용히 버리지 않고 실패로 처리한다.
관측되지 않은 후보의 출력은 공통 mask로 제외한다.

## 학습/선택/평가

- 시스템별 모델 학습. hidden32/dropout0.1, Adam lr0.001/weight_decay0.0001.
- seeds11,23,37, 최대80 epoch, full batch, CPU.
- validation cross-entropy 최소 checkpoint 선택. training이나 test 점수로 선택하지 않음.
- 동일 설정의 준비도 smoke이며 모델별 튜닝/용량 최적화가 아니다.
- 원인 서비스 하나를 예측하는 사고 단위 Top-1/Top-3/MRR.
- 정확한 동점은 균등 무작위 순서를 가정한 기대 적중률/역순위로 채점.
- 정상 라벨 -1은 root 진단 지표 분모에서 제외. 잘못된 정답/후보/NaN은 오류 처리.
- 단순 train-root-frequency prior를 같은 평가기로 채점하여 기억만으로 가능한 성능 표시.
- 검증 성능은 checkpoint 선택에 사용했으므로 비편향 최종 시험 성능이 아니다.
- 각 seed의 학습 손실, 선택 epoch, 파라미터 수, shape, 최종 선택 state hash,
  원자료 접근 목록과 코드/명세 hash를 기록한다. 실패 seed/사례를 제외하지 않는다.
