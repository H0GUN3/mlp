# RCA 스모크 결과 감사

오프라인 검증은 저장된 48개 응답의 순위를 독립 채점했다. 기록된 결과는 카드만 1/12, 전체 호출 1/12, 규칙 선별 2/12, 같은 개수 무작위 선별 1/12 Top-1이다. 단순 이상점수 순위는 11/12, 사후 합성 sanity는 2/2다. 규칙 선별은 전체 호출·무작위보다 각각 1건 앞섰지만, 카드만 조건보다도 1건 앞섰을 뿐이다. 따라서 이 결과는 호출 선별의 추가 효용을 입증하지 않는다. 표본 12건의 탐색 스모크이므로 유의성, 일반화, 운영 개선을 주장할 수 없다.

조건별 평균 입력 토큰은 카드만 2603, 전체 호출 2836, 규칙/무작위 각 2668이다. 평균 LLM 서버 시간은 각각 0.929초, 1.060초, 0.994초, 0.965초다. 이는 모델 요청의 서버 측 `total_duration`이며 전처리와 전체 실험 비용이 아니다. 요청 `wall_seconds`도 호출 요청 시간이지 end-to-end 시간이 아니다. 별도 전처리 기록은 12건의 feature 생성 시간 합계로 보고서에 남기지만, 전체 end-to-end 지연을 재측정한 값은 아니다.

중요한 한계:

- 정답은 원인 서비스뿐이며 RCAEval에는 전파 연결 정답이 없다. 관측 호출은 인과관계가 아니며 방향도 전파 방향을 보장하지 않는다.
- 입력은 익명 서비스 카드와 지표·트레이스 요약뿐이고 로그는 제외됐다. 따라서 다중 관측자료 기반 RCA를 검증하지 않았다.
- 12건은 두 시스템의 장애 유형별 1건씩인 고정 작은 표본이다. 같은 원인/장애유형의 나머지 2건은 개발 예약군이며 독립 시험 표본이나 추가 성공으로 세지 않았다.
- 합성 sanity 2/2는 단순히 두 입력에서 응답이 지정 서비스를 1위로 두었음을 보일 뿐 실제 사고의 진단 능력 증거가 아니다.
- 단순 이상점수 11/12가 LLM 조건보다 높다. 현재 관찰은 모델이 이 표본에서 정량 기준점보다 낫다는 근거를 주지 않는다.

재현 실행 명령과 검사별 상태·원천 SHA-256은 `research/verification/smoke-checks.json`에 기록했다. 불변식 불일치는 해당 보고서에 실패로 남기며 실험 산출물을 수정하지 않는다.
