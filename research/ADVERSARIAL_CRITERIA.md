# 연구 타당성 반증 기준

사용자는 연구 가치·핵심 문제·방법론을 강하게 압박해 평가할 것을 요청했다.
36건의 기준점 결과를 보기 전에 아래 판정 원칙을 고정한다.
목표는 현재 아이디어를 살리는 것이 아니라, 근거가 없는 방향을 일찍 중단하는 것이다.

## 반드시 분리할 네 주장
1. 일반적으로 중요한 운영 문제가 존재한다.
2. 그 문제가 우리의 데이터와 과제에서 실제로 관측된다.
3. 제안 방법의 작동 원리가 그 문제를 해결한다.
4. 기존 방법 대비 새로운 지식이나 유의미한 실용적 이점이 있다.

1이 참이라고 2~4가 따라오는 것은 아니다. RCA가 중요하다는 말만으로 이 방법의
연구 가치가 확보되지 않는다.

## 공격 질문과 통과에 필요한 근거

| 관점 | 공격 질문 | 필요한 근거 / 기각 조건 |
|---|---|---|
| 문제의 실재성 | 원인·피해 혼동이 실제 실패 원인인가, 설명하기 쉬운 이야기인가? | 원인 정답·관측 특징·기준점 실패의 사례별 증거. 비원인 서비스라는 이유만으로 피해 서비스라 부르면 안 됨 |
| 문제의 크기 | 강한 단순 방법이 대부분 맞히는데 왜 복잡한 모듈이 필요한가? | 반복 그룹을 고려한 실패 범위와 영향. 작은 개선 여지에 과한 방법이면 보류 |
| 데이터 적합성 | 주입 도구의 뚜렷한 자원 신호만 찾는 문제가 아닌가? | 현재 주입 장애의 한계를 명시. 운영/코드 결함 일반화는 별도 증거 없으면 금지 |
| 구현 오류와 연구 문제 | 시작 시각·단위·필터·동점·결측 버그를 새로운 RCA 난제로 착각한 것은 아닌가? | 기본 구현·전처리 검증 먼저. 단순한 수정으로 해결되면 복잡한 제안 방법의 동기로 삼지 않음 |
| 방법의 적합성 | 관측이 없는데 추론 모델을 바꾸면 정보가 생기는가? | 필요한 증거가 입력에 존재하는지 확인. 정보 부족·표현 손실·판단 오류를 구분 |
| 신규성 | MicroHECL/EviRCA/TopoEvo/EG-RCA의 선택·가지치기를 다시 포장한 것은 아닌가? | 무엇이 다른지 구체적인 연산·학습 정답·비용·실패 조건으로 설명. 조합만 다르면 불충분 |
| 학습 정답 | 학습하려는 대상과 보유한 정답이 같은가? | root-service 감독과 propagation-edge 감독을 분리. 호출 관계를 전파 gold로 쓰면 기각 |
| LLM 역할 | 수치 순위기가 하는 일을 LLM이 더 비싸고 부정확하게 하는 것은 아닌가? | 같은 추가 정보를 사용하는 비LLM 보완과 비교. 자연어 설명을 붙이는 것만으로 필요성 인정 안 함 |
| 공정한 비교 | 약한 자체 baseline이나 미검증 재구현을 이겨 놓고 기존 연구를 이겼다고 하는가? | 실행된 통제·원본 코드·코드 정렬 재구현·논문 재현을 구분. 같은 정보·정답·시간 조건 |
| 통계와 누출 | 반복 3건을 독립 3개 증거로 세거나 개발 사례를 시험에 재사용하는가? | 그룹 단위 분할·집계, 독립 시험. 12→36건 확대가 독립 조건 3배라는 주장 금지 |
| 불리한 결과 | 실패 후 프롬프트·지표를 바꾸고 처음부터 성공한 것처럼 보고하는가? | 첫 결과 보존, 탐색과 확증 분리. 불리한 기준점·실패 응답도 포함 |

## 이번 단계의 판정 범주
- **진행:** 구체적인 문제 증거와 그에 대응하는 방법 가설이 있고 작은 검증 경로가 있다.
- **수정:** 문제는 유효하지만 방법/범위/비교가 맞지 않는다. 수정 대상과 이유를 특정한다.
- **보류:** 데이터·실패 근거·정답·비교가 부족하다. 먼저 충족할 조건을 지정한다.
- **폐기:** 현재 기여 주장이 이미 알려진 내용이거나, 새 방법이 필요하다는 근거가 없다.
  특정 기여안을 폐기하는 것과 RCA 연구 분야 전체를 폐기하는 것을 구분한다.

반증 검토도 과장하지 않는다. Qwen3:8b의 한 설정 실패로 모든 LLM이 불필요하다고
주장하거나, 36건 개발 분석으로 이 분야가 해결됐다고 주장하지 않는다.

## 후속 DAG
기준점 단계의 검증된 결과를 받은 뒤, 문제 실재성·신규성·방법/평가 타당성을
서로 다른 작업으로 검토하고 종합 판정을 작성한다. 각 반박은 근거, 치명도,
해소 가능한 최소 검증, 해소되지 않을 때 중단할 주장을 함께 제시한다.
