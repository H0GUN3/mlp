# 원형 재현과 공정한 개선 실행 계획

## 이후 사용자 정정 — 2026-10-13

원 논문 모델을 개선하는 작업은 하지 않는다. 기존 복원본은 외부 비교 대상으로
보존한다. 사용자가 선택한 원 논문 SN/TT 자료에서 **제안 방법론에 따른 자체
기준선과 자체 제안 모델**을 만들며, 후속 실행 계약은
`../method_mlp_20261013/PROTOCOL.md`를 따른다.
RCAEval 특정 사건의 원형 재검증은 미확인으로 남기고 최종시험36건은 계속 봉인한다.

## 고정 목표

데이터가 임의 제작물이 아닌지 확인하고, 원래 관측 처리·모델·학습 목적을 보존한
기준점을 실행한 다음, 반복 오답의 원인을 확인하고 필요한 변경만 비교한다.
성능 개선은 목표이지 미리 약속한 결과가 아니다.

## 순서와 범위

1. 기존 RCAEval/ops-lite의 출처 및 양·품질 판단은 기존 검수 근거를 재사용한다.
   RCAEval은 공개 벤치마크지만 특정 주입 조건의 시험이다. 현재 학습54건/검증18건
   (시스템별)의 작은 자료만으로 폭넓은 개선을 보장하지 않는다.
2. Eadro 저자 연결 Zenodo record7615394의 SN/TT를 `data/eadro_native/`에 별도 확보한다.
   압축 파일 약128MB. 게시된 MD5, 자체 SHA256, ZIP 경로/CRC/크기를 검사한다.
   기존 RCAEval/ops-lite와 실험 결과는 수정하지 않는다.
3. 원 코드의 log HawkesADM4, metric/trace 시간흐름 인코더, 결합기·판단기와 공동
   학습 목적을 유지한다. 17개 요약 숫자로 다시 축약하지 않는다.
   먼저 저자 지정 tick0.7.0.1과 호환되는 격리 환경을 확보한다.
4. 실제 파일 구성을 본 뒤 사고/수집 run/시간 구간의 대응을 확인하고 분할을 고정한다.
   원 논문의 수정된 split/seed/설정이 공개되지 않았다면 정확한 수치 재현이라 부르지 않는다.
   같은 원 자료·핵심 방법을 사용한 공개적 수정 프로토콜과 구분한다.
5. 양쪽에 같은 정규화/분할/학습 선택/채점 수정을 적용한다.
   전체 자료 정규화, 겹치는 창의 분할, 시험 점수 선택, all-normal loss,
   시간대 불일치 등은 먼저 검증한다. 교정 없이 그대로 베끼지 않는다.
6. DiagMLP의 본문 식에 맞춘 입력 결합 경계를 명시하고, 확인되지 않은 저자 구현과
   동일하다고 주장하지 않는다. 상세 근거는 `fidelity_audit.md`.
7. 첫 완전 실행에서 1회 학습 시간/메모리를 측정하고 정식 비교의 실행 예산을 고정한다.
   기준점과 제안 변경에 비교 가능한 튜닝 기회를 준다. 검증 결과를 보고
   더 유리한 데이터/분할로 바꾸지 않는다.
8. 기존 검증 오답은 먼저 저장 모델과 원 관측을 대조한다. 원형 처리에서도 남는지
   확인하지 않고, 간소화판의 오류를 원 논문 한계라고 부르지 않는다.
9. 확인된 약점에 한해서 최대 두 가지 기제 가설을 검증한다. 모델 종류·입력 접근·
   후보·라벨·분할·학습 예산·선택 기준을 결과 전에 기록한다.
   작은 평균 상승만으로 개선을 선언하지 않고 반복 실행과 사례/조건별 차이를 보고한다.

## 경계와 복구

- 기존 RCAEval 최종시험36건은 개발·진단·튜닝에 열지 않는다.
- 새로운 원 논문 자료는 먼저 분할/품질/계약을 정한 후 학습과 평가에 사용한다.
- 모든 새 파일은 r2의 별도 경로. 전용 환경은 `.venv-eadro`, Python은 사용자 소유 경로.
  root/공용 계정/omo-native/Notion을 건드리지 않는다.
- 미완료 다운로드는 `.partial`; 검사 후 완성 파일로 전환한다.
  기존 완성 파일이 있으면 해시를 확인하고 덮어쓰지 않는다.
- 패키지 호환 실패나 비공개 artifact가 나오면 그 원인과 실제 시도를 기록한다.
  임의 대체 구현으로 원형 재현을 가장하지 않는다.

## 현재 규모에 대한 객관적 판단

기존 간소화판 OB96.3%는 개선 여지가 작고, TT81.5%는 실행별 변동이 컸다.
원고의 TT98.5%와 직접 비교할 수 없다. 새 원형 기준점의 성능을 보기 전까지
제안 모델의 기대 개선폭을 수치로 약속할 근거는 없다.
원 논문의 자료를 확보해도 반복/시간창을 독립 사고로 세면 안 된다.
새 자료의 실제 독립 단위와 원형의 실패 양상이 연구 가능성을 결정한다.
