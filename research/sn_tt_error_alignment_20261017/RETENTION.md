# TT 유지 및 교차 데이터셋 해석 기준

## 목적과 범위

목표는 효율 비교가 아니라 **각 데이터셋에서 따로 학습한 모델의 진단 정확도**다. 공통 원칙과 비교할 변경 하나를 적용하되, SN과 TT는 각각 자체 자료로 학습·평가한다. 본 문서는 TT 성능 유지 판단의 틀과 다른 데이터셋 결과를 해석할 경계만 정한다. 손실 허용폭은 사용자 합의 전까지 미정이다.

여기서 “같은 원칙”은 같은 평가 정의와 대응되는 기준선-변경안 비교를 뜻한다. 서로 다른 시스템에서 학습한 가중치, 입력 공간, 후보 서비스를 같게 만들거나 하나의 모델로 합치는 뜻이 아니다.

## 평가 원칙

- 주 지표: 장애로 확인된 창에 한정한 **조건부 root-cause Top-1**. 이는 모델이 장애 창에서 실제 원인 후보를 1위로 올린 비율이며, 장애 탐지 성공률까지 곱한 전체 파이프라인 성공률은 아니다.
- 함께 보고할 지표: 같은 장애 창에서의 조건부 Top-3.
- 보조 지표: 장애 탐지 결과로 걸러낸 뒤 계산하는 gated Top-1/Top-3. 탐지 실패가 원인 진단 결과에 어떤 영향을 주는지 드러내되 주 지표를 대체하지 않는다.
- 동일 데이터셋·동일 split·동일 채점 정의 안에서만 기준선과 변경안을 짝지어 비교한다. 데이터셋별 차이는 따로 제시하고 합쳐 단일 효과처럼 표현하지 않는다.
- seed 간 변동만으로 표본의 독립성을 주장하지 않는다. 반복 창이 동일 사건/recording에서 왔는지와 split 간 공유 여부를 구분한다. seed·사건·창의 불확실성은 현재 허용된 요약자료만으로 확정할 수 없으면 미확인으로 남긴다.
- validation은 선택·개발 자료다. 이를 다시 독립 최종시험처럼 사용하지 않는다. 본 문서는 새 split이나 추가 데이터를 만들거나 지정하지 않는다.

## TT 유지 판정

변경안이 TT에서 얼마나 낮아져도 허용되는지는 **합의 전 미정**이다. 임의의 비열등성 한계, 신뢰수준 또는 통계검정 통과 조건을 본 문서가 정하지 않는다.

사용자가 허용폭과 판단 단위를 정한 뒤, 같은 TT 평가 조건의 기준선과 변경안에서 조건부 Top-1을 짝지어 대조한다. Top-3 및 gated 지표는 함께 공개해 Top-1 변화만으로 생길 수 있는 오해를 줄인다. seed별 결과와 요약자료에 있는 변동은 출처 정의 그대로 제시하되, 그것만으로 독립 사건 수준의 불확실성을 안다고 주장하지 않는다.

현재 확인된 TT 기준선은 별도 조건의 결과들이므로 서로 대체하거나 한 줄의 연속 비교로 섞지 않는다.

| 논문 보고치 | DiagMLP Top-1 98.5%, Top-3 99.7%; Eadro Top-1 91.1%, Top-3 96.5% | DiagMLP v2 §IV/Table IV, TT 행. 논문 내 Eadro backbone 비교이며 로컬 실행 결과가 아니다. 논문 Table I은 TT를 train 3256 / valid 813 / test 1744로 적는다. |

## 다른 데이터셋 결과의 해석

DiagMLP 논문은 데이터셋마다 그 데이터셋의 backbone을 바꿔 끼운 **별도 비교**다. 원문 §IV-A/§IV Table IV와 로컬 `../research_handoff_20261016/DIAGMLP_DATAFLOW_AND_VALIDITY.md` §4에 따르면 SN·TT는 Eadro 기반, GAIA는 TVDiag 기반이다. 논문 Table IV의 해당 Top-1은 SN 41.8→80.2%, TT 91.1→98.5%, GAIA 59.8→61.0%다. 이 값들은 서로 다른 자료와 backbone에 대한 보고치이지, SN에서 TT로 학습·전이한 결과나 하나의 공통 개선량이 아니다. 논문 §IV-A의 SN/TT 전처리 재구현 및 평가 설정도 고려해야 한다.

따라서 현재 허용된 주장은 “같은 원칙의 변경을 각 데이터셋 안에서 기준선과 짝지어 평가한다”까지다. 다음 주장은 이 범위 밖이며 본 분석에서 만들지 않는다.

- SN에서 학습한 모델을 TT에 그대로 적용하는 교차 시스템 전이.
- 새 시스템·데이터셋 도입, cold-root/미관측 고장 일반화, 데이터셋 채택 또는 우열 순위.
- 서로 다른 backbone·전처리·후보 집합의 수치를 직접 합산하거나, 차이를 모델 변경 하나의 효과로 귀속.

SN의 반복 오류는 기존 허용 요약/분석에서 실제로 확인된 오류와 반복 단위를 근거로만 말한다. 원인 후보 쌍이나 오류 메커니즘이 요약 근거에 없다면 정확도 수치만으로 추정하지 않는다. 이는 TT 유지 기준을 정하는 본 문서에서 별도 SN 오류를 추가 발굴하거나 새 방법을 설계한다는 뜻이 아니다.

## 증거 상태와 금지된 추론

- **관측:** 위에 인용한 논문 표와 로컬 중간 보고서에 실제로 기록된 점수·split 사실.
- **모델 충실도/재현 한계:** `../native_reproduction_20261013/fidelity_audit.md` “Evidence and status” 및 “Fusion boundary: supported versus unknown”은 공개 수리 포크와 수식 기반 복원, 저자 통합의 미확정 부분을 구분한다. 로컬 점수를 원저자 코드의 완전 재현 결과로 부르지 않는다.
- **제안 기준:** 조건부 Top-1 중심, Top-3 및 gated 지표 동시 보고, 사용자 합의 전 허용폭 미정은 이번 문서의 평가 원칙이다. 아직 실행되거나 통계적으로 검증된 유지 결과가 아니다.

오류 관측만으로 전파, 결측, 그래프 부재, 정규화 또는 특정 모달리티를 원인으로 확정하지 않는다. 이미 기록된 SN169+1, TT1744+1, RE2 관측은 보존 대상이며 열람·재채점·재해석으로 범위를 넓히지 않는다. TT 보호 시험, NPZ, checkpoint, 저장 예측 배열을 읽지 않으며 학습·추론·전처리도 수행하지 않는다. 추가 자료는 향후 별도 합의가 있을 때만 고려한다.
